One-Time Firebase Setup

To enable real-time sync across all office PCs, connect your Firebase database. This takes 5 minutes and is done once per browser.

1
Go to console.firebase.google.com → Create project → name it sparksco-wm
2
Click Realtime Database → Create Database → Start in test mode
3
Go to ⚙ Project Settings → Your Apps → Web → Register app → Select Config radio → Click Copy
4
Paste the config below (the JSON object only — remove const firebaseConfig = and ;) then click Connect
